# 🏎️ HandDrive Racing

A hand-gesture controlled racing game built with Python.

## 🎮 Controls

- ✋✋ Move both hands left/right → Steering
-Both hands completly up nitro 
- Both hands down break
- W → Accelerate
- S → Brake
- A / D → Keyboard steering
- Space → Nitro
- R → Restart

## 🛠️ Technologies

- Python
- Pygame
- OpenCV
- MediaPipe
- Computer Vision

## ✨ Features

- Real-time hand tracking
- Gesture-based steering
- Nitro system
- Brake system
- Enemy cars
- Coin collection
- Collision detection
- Score system
